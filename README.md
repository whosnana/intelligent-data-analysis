## Опис проєкту

Репозиторій **`intelligent-data-analysis`** — це навчально-дослідницький проєкт із **інтелектуального аналізу даних (Data Mining)**.  
Основна мета — **аналіз ефективності косметичних брендів** за допомогою часових рядів, кластеризації, класифікації та оптимізаційних методів.

Проєкт моделює бізнес-процеси таких брендів, як *L'Oréal, Fenty, Rare Beauty, Sephora, Maybelline* — аналізуючи продажі, прибуток, рекламний бюджет і показники ефективності (ROI).

---

## 📊 Особливості даних

**Структура вхідного файлу:**

| Поле | Опис |
|------|------|
| `date` | Кінець місяця у форматі *MonthEnd* (частота **ME**) |
| `sales` | Продажі бренду (тис. грн) |
| `marketing_spend` | Рекламний бюджет (тис. грн) |
| `profit` | Прибуток бренду (тис. грн) |
| `roi` | Відношення прибутку до витрат (рентабельність) |

> Формат CSV або Excel використовується як вхідний набір даних для більшості скриптів у репозиторії.

## Вимоги до середовища

### Рекомендовано

- Python **≥ 3.10** (підтримано 3.11–3.13)  
- Менеджер пакетів `pip`  
- Віртуальне середовище `venv`

### Мінімальні бібліотеки

```bash
  pip install numpy pandas matplotlib scikit-learn statsmodels scipy lifelines seaborn
```
### Додаткові бібліотеки

- `scikit-fuzzy` — нечітка логіка Мамдані  
- `networkx` — графові структури нечітких систем  
- `lifelines` — survival-аналіз (регресія Кокса)

## Як запустити локально

### 1. Клонування репозиторію

```bash
     git clone https://github.com/whosnana/intelligent-data-analysis.git
cd intelligent-data-analysis
```
### 2. (Опціонально) створення віртуального середовища

```bash
  python3 -m venv .venv
source .venv/bin/activate          # macOS / Linux
# або
.venv\Scripts\activate             # Windows
```
### 3. Встановлення бібліотек

```bash
  python3 -m pip install --upgrade pip
```
