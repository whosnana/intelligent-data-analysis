# Мета:

Ознайомитися з методами аналізу часових рядів у Python та провести розкладання й прогнозування показників продажів косметичних компаній (наприклад, L’Oréal, Fenty Beauty, Sephora) за допомогою моделей тренду, сезонності та випадкових складових.

# Завдання:

1. Імпортувати дані про продажі косметичних брендів за місяцями.

2. Побудувати графік динаміки продажів та виявити наявність тренду.

3. Розкласти часовий ряд на складові (тренд, сезонність, залишки).

4. Побудувати автокореляційну функцію для перевірки стаціонарності.

5. Побудувати модель ARIMA для прогнозування наступних періодів.

6. Візуалізувати результати прогнозу.

7. Зробити висновки щодо сезонності, тренду та точності прогнозу.

# **Використані технології**

Мова програмування: Python 3.13

## Бібліотеки:

pandas — обробка даних

numpy — математичні операції

matplotlib, seaborn — побудова графіків

statsmodels — аналіз часових рядів, ARIMA, ACF

# Очікувані результати:

Графік динаміки продажів (тренд і сезонність).

Розкладення часового ряду на компоненти (Trend, Seasonal, Residual).

Графік автокореляції залишків.

Прогноз на 6 майбутніх місяців.

# Висновки:

1. У продажах косметичних брендів простежується чітка сезонність (підвищення влітку й перед святами).

2. Тренд показує зростання попиту на косметику.

3. Модель ARIMA(1,1,1) дозволяє будувати прогноз із прийнятною точністю.

4. Аналітичний підхід на Python може замінити STATISTICA для дослідження ринкових трендів у косметичній сфері.
