## Опис проєкту
**Cosmetics Analytics Platform** — аналітична система для дослідження ефективності косметичних брендів із використанням інтелектуального аналізу даних (**Data Mining**), машинного навчання та візуалізації.

Система моделює бізнес-процеси брендів *L'Oréal, Fenty, Rare Beauty, Sephora, Maybelline*, аналізуючи продажі, прибуток, рекламні витрати та показники ефективності (**ROI**).

---

##  Особливості даних
**Структура базового файлу `brands_data.csv`:**

| Поле | Опис |
|------|------|
| `date` | Кінець місяця (формат *MonthEnd*) |
| `brand` | Назва бренду |
| `sales` | Продажі бренду (тис. грн) |
| `marketing_spend` | Рекламний бюджет (тис. грн) |
| `profit` | Прибуток (тис. грн) |
| `roi` | Рентабельність (прибуток / витрати) |

> Формат CSV або Excel використовується як основний вхідний набір даних.

##  Вимоги до середовища
### Рекомендовано
- Python **≥ 3.10** (підтримано 3.11–3.13)  
- Менеджер пакетів `pip`  
- Віртуальне середовище `venv`  

### Мінімальні залежності
numpy, pandas, matplotlib, scikit-learn, statsmodels, scipy, lifelines, seaborn  

### Додаткові бібліотеки
- scikit-fuzzy — нечітка логіка Мамдані  
- networkx — графові структури нечітких систем  
- lifelines — survival-аналіз (регресія Кокса)

## Як запустити локально
### 1. Клонування репозиторію
git clone https://github.com/whosnana/intelligent-data-analysis.git  
cd intelligent-data-analysis/cosmetics_analytics_platform  

### 2. (Опціонально) створення віртуального середовища
python3 -m venv .venv  
source .venv/bin/activate          (macOS / Linux)  
або  
.venv\Scripts\activate             (Windows)  

### 3. Встановлення залежностей
python -m pip install --upgrade pip  
pip install -r requirements.txt  

### 4. Запуск застосунку
streamlit run app.py  

Після запуску відкрий у браузері:  
http://localhost:8501

## Основні модулі
| Модуль | Опис |
|--------|------|
| loader.py | Завантаження та підготовка даних |
| kpi.py | Розрахунок ключових показників ефективності (KPI) |
| segmentation.py | Кластеризація бізнес-моделей (KMeans) |
| timeseries.py | Прогнозування продажів (Holt-Winters / ARIMA) |
| survival.py | Survival-аналіз брендів (регресія Кокса) |
| insights.py | Генерація текстових аналітичних висновків |
| translation.py | Українська локалізація інтерфейсу |
| app.py | Основний Streamlit-додаток із інтерактивними панелями |

## Інтерактивний аналіз
Платформа дозволяє:
- обирати бренд для аналізу та прогнозу;  
- вводити власні дані бренду;  
- будувати графіки продажів, прибутку та ROI;  
- кластеризувати бренди за ефективністю;  
- отримувати рекомендації через модуль **AI Insight Generator**.  

---

## AI Insight Generator
Модуль генерує автоматичні аналітичні висновки на основі введених користувачем даних:
- аналізує ROI та прибутковість бренду;  
- пропонує стратегії підвищення ефективності;  
- виявляє сильні сторони бренду;  
- прогнозує ризик зниження продуктивності.  

---

## Візуалізації
Система створює понад **15 інтерактивних графіків**, серед яких:
- продажі у часі;  
- сезонність і тренди;  
- залежність продажів від реклами;  
- кластеризація брендів;  
- survival-криві життєвого циклу бренду;  
- ROI-порівняння між брендами;  
- графіки для користувацьких даних.
